# 在线录制 MP3 音频

> 浏览器内录音并编码为 MP3，可本地回放下载。

在线体验：https://wangchenyu.com/gongju/recorder/

## 功能特性

- 麦克风实时录音
- 录制 MP3 音频
- 本地回放

## 使用方法

1. 用浏览器直接打开 `index.html`，无需安装任何软件、无需构建、无需后端服务。
2. 所有计算与处理均在浏览器本地完成，数据不会上传到服务器。
3. 处理完成后使用页面上的复制 / 导出按钮即可保存结果。

## 技术栈

JavaScript Recorder 库 + Web Audio API

## 目录结构

```
├── index.html        # 主页面
├── assets/ 或本地资源 # 样式、脚本与静态资源（按需）
```
